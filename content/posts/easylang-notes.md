## 2、不等于号≠如何打？

直接打小于号和大于号：“\<\>”即可自动显示不等于号。或者打感叹号和等于号“！=”。

## 3、如果真和判断的区别？

### 一句话分清

- **如果真**：**有条件才执行，没条件就跳过**（单路）。

- **判断**：**多个条件选一个，先满足先执行**（多路互斥）。

### 对应关系（和 C 语言类比）

- 如果真 → `if (...) { ... }`

- 判断链 → `if (...) { ... } else if (...) { ... } else { ... }`

## 4、什么是句柄？

**句柄 = 窗口的唯一身份证**

句柄是 Windows 给程序的「资源访问通行证」，程序拿着通行证找系统，系统再帮你操作资源，既保证了安全，又实现了多任务资源共享。

### 通俗类比：把系统比作图书馆

- **系统资源**：图书馆里的书（窗口、文件、线程等）。

- **句柄**：你借书时拿到的「借书卡编号」。

- **系统内核**：图书馆管理员，手里有一张「编号→书」的对照表。

你不能直接冲进书库拿书（不能直接访问资源地址），只能拿着借书卡编号（句柄）找管理员，管理员帮你找到书并交给你操作。当你还书时（关闭句柄），管理员会把编号回收，这本书就和这个编号解绑了。

### 如何理解句柄跟内存地址？

**内存地址 = 直接敲门（危险，容易直接弄坏）**

**句柄 = 物业给你的门禁卡（安全，间接操作）**

## 5、执行和运行的区别？

1. **用****`执行()`****直接运行\.exe 也能成功，但不推荐**

    - 因为`执行()`会先去查系统关联，再启动程序，多了一层步骤，效率低，也没法控制进程的启动方式。

    - 正确做法：运行\.exe 用`运行()`，打开文件 / URL 用`执行()`。

2. **`运行()`****不能直接打开\.txt/\.jpg**

    - 你给`运行()`传一个\.txt 路径，会直接报错，因为它只认可执行文件。

    - 这种情况必须用`执行()`，或者先找到对应的程序（比如 notepad\.exe），再用`运行()`打开。

## 6、三个类型各个变量的区别？

**局部变量**：只给自己一个子程序用

**程序集变量**：本窗口大家一起用

**全局变量**：整个软件所有地方随便用

## 7、如何看待易语言的子程序？

- **定义**：子程序是封装特定功能、可被重复调用的代码块，等价于其他语言的**函数 / 过程**。

- **分类**：

    - **事件子程序**：系统预定义（如`_按钮1_被单击`），自动触发，签名不可改。

    - **自定义子程序**：用户自由定义，可无参 / 带参、无返回 / 有返回，支持嵌套与递归。

- **核心价值**：**分而治之**—— 复用代码、简化结构、便于调试与维护。

## 8、动态数组和静态数组的区别？

**静态数组**：**数量提前知道，永远不变** → 用静态，简单省事

**动态数组**：**数量未知、会增减** → 必须用动态（注意：动态数组必须在数组一栏要加上0才表示动态数组）

## 11、什么是本机IP、内网IP和外网IP？什么是端口？

**本机 IP = 你的设备在局域网里的地址（就是内网 IP）**

**内网 IP = 路由器分给你家设备的内部地址**

**外网 IP = 运营商给你家的对外互联网地址**

### 举个例子

你家：

- 手机内网 IP：`192.168.1.100`

- 电脑内网 IP：`192.168.1.101`

- 全家共用外网 IP：`123.45.67.89`

### 端口是什么

端口是**0～65535**之间的数字，用来区分一台电脑上不同的网络程序。

- 80 端口：网页（上网）

- 443 端口：加密网页（HTTPS）

- 22 端口：远程连接

- 3389 端口：Windows 远程桌面

- 游戏、软件也会占用自己的端口

### IP \+ 端口 = 精准定位

比如：`192.168.1.100:8080`

- `192.168.1.100`：哪台电脑

- `8080`：这台电脑上的哪个软件

### 内网端口 / 外网端口

- 内网端口：你电脑内部软件用的端口

- 外网端口：路由器映射出去，互联网能访问的端口

## 14、\#号的作用

`#` 是易语言**专用常量 / 资源调用符**

主要用途：调用**系统常量、自定义常量、图片、声音、组件默认属性**

写法固定：`#常量名` / `#资源名`

好处：代码简洁、不易写错、可读性强

```C++
' 消息框按钮
信息框 (“提示”, #确认钮, “标题”)

' 窗口样式
_启动窗口.边框 ＝ #无边框

' 颜色常量
标签1.背景颜色 ＝ #红色
```

## 17、窗口句柄和线程句柄的区别？

**句柄**（Handle）= Windows 给资源分配的唯一数字编号 系统里的窗口、线程、文件、进程、画笔…… 都会被分配一个整数 ID，程序靠这个 ID 找到对应资源。 你可以理解成：门牌号，系统靠门牌号找人 / 找房间。

**窗口句柄：**管窗口，做后台识图、后台点击、控制窗口必备，大漠核心依赖。

**线程句柄：**管代码执行流，用来开启、暂停、关闭多线程。

两者都是数字编号（门牌号 / 工号），只是管理的对象不一样。

## 18、为什么易语言通常在一些操作中加延时?

代码运行速度＞游戏画面加载速度，延时就是等画面、等进程、仿人手、稳多开。

## 19、独立编译、静态编译和编译为易包的区别？

1. 独立编译：exe很小，要带支持库才能运行

2. 静态编译：单exe无依赖，发给别人直接用，体积大

3. 编译易包\(epk\)：插件库，不能单独打开，供程序动态加载调用

## 20、易语言模块加载有什么用处？

### 1\.复用代码，不用重复写

把网络、图色、窗口、加密等通用代码打包成模块，新建项目直接导入，不用每次重写几十上百行基础代码（比如精易模块）。

### 2\. 简化代码，降低开发量

模块封装好现成命令，一行调用搞定复杂功能。

例：`网页_访问()` 替代自己写API、编码、请求头一大堆代码。

### 3\. 项目分层，方便维护

功能分开打包（大漠模块、爬虫模块、界面模块），代码不乱，多人协作、后期改逻辑更清晰。

### 4\. 封装隐私代码，防止源码泄露

\.ec模块编译后看不到内部源码，只暴露可用命令；核心算法、付费脚本逻辑可以打包给别人用，不会被盗走。

### 5\. 统一标准，减少出错

成熟模块（精易、EXUI）经过大量测试，比自己手写API稳定，少踩内存、编码、兼容性bug。

### 6\. 共享分发

做好的功能打包成\.ec，发给别人直接导入就能用，不用复制一堆子程序。

### 补充区分

- 模块 `.ec`：给易语言工程调用，写代码时用；

- 支持库 `.fne`：IDE底层增强、控件库，启动易语言就加载。

## 12、易语言的执行顺序

很多人会混淆「程序入口」，这里给你理清楚完整流程：

1. **系统加载程序** → 2\. 加载 `_启动窗口` → 3\. 窗口创建完成，触发 `__启动窗口_创建完毕` → 4\. 执行里面的代码 → 5\. 窗口显示给用户

- 窗口没创建完的时候，控件的句柄、内存都没分配，你提前调用控件操作会直接崩溃或报错。

- 所以**所有依赖窗口 / 控件的初始化代码，都必须写在 ****`__启动窗口_创建完毕`**** 里面**，这是易语言的核心规则。

16、计次循环首在第一次循环时会自动把你传入的变量（n）赋值为1。

```C++
.局部变量 n, 整数型  ' n初始是0
计次循环首 (20, n)
```

循环运行时：

1. 第一次循环，系统**自动把 n 赋值为 1**

2. 第二次 → n=2

3. … 直到 n=20 结束

16、注意查找非中文的文本可以直接调用“寻找文本”这个函数，但查找中文的文本需要用“寻找字节集”这个函数才能查找得到，这是易语言本身的bug。
